# Muhammad Fachry Alfareeza Portfolio

A responsive, single-page portfolio for software engineering, data analysis, and applied AI work. The site is a static GitHub Pages project with no build step.

## Run locally

From this folder, start a local server so the browser can load `data.json`:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Update content

Edit `data.json` to update the profile, social links, grouped skills, projects, experience, education, training, and awards. Keep project descriptions specific and label prototypes or mockups clearly. The page structure is in `index.html`, visual styles are in `styles.css`, and rendering/filter behavior is in `app.js`.

Replace `assets/Fachry-Alfareeza-ATS-CV.pdf` whenever the downloadable CV changes.

## Publish

Push the updated files to the repository's GitHub Pages branch. The live portfolio URL is <https://fachryalfareeza.github.io/Portfolio>.
